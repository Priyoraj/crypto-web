Playfair Cipher

Letters are encrypted two at a time using a 5×5 square built from a key word. I and J share a cell, and anything that is not a letter is ignored.

Rules used
  1. Split the text into pairs of letters. If both letters of a pair are the same, put X between them (Q if the letter is X). If one letter is left over at the end, add X (Q after an X).
  2. Both letters in the same row: replace each with the letter to its right, wrapping round to the start of the row.
  3. Both letters in the same column: replace each with the letter below it, wrapping round to the top.
  4. Otherwise: replace each letter with the one in its own row and the other letter’s column.

Decryption does steps 2 to 4 in reverse (left instead of right, up instead of down). The filler letters are still in the decrypted text. The best guess drops an X (or a Q after an X) that sits between two equal letters or at the very end, so it can also drop an X that was really in the message.
